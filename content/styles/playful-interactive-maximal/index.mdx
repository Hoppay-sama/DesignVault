# Playful Interactive Maximal

**Saturated colors, gamified interactions, physics-based hovers, surprise moments. Engagement over conversion.**

## Visual DNA
Bold, saturated color palettes with gamified interactions. Every hover, click, scroll triggers surprise — confetti, sound, morphing shapes. Page feels like a toy. Fullscreen sections, unexpected navigation, scroll-jacking for storytelling.

## Design Principles
1. **ENGAGEMENT OVER CONVERSION** — Campaign, not sales page
2. **SURPRISE AS STRUCTURE** — Every interaction has delightful response
3. **FULLSCREEN IMMERSION** — Each section is a world

## Typography
- Bold display sans (Druk, Anton, Big Shoulders)
- Mixed with playful custom lettering

## Color
- Saturated polychrome (electric pink, cobalt, lime, tangerine)
- High-contrast combinations

## Motion
- Physics-based interactions
- Particle effects
- Sound-reactive elements
- Gamified hover states
- Scroll-jacking

## Layout
- Fullscreen sections
- Unexpected navigation patterns
- Scroll-jacking for storytelling

## Texture
- Clean digital surfaces
- 3D rendered elements
- Illustrated overlays

## Vocabulary
**Primary:** `gamified interaction`, `particle effect`, `physics-based hover`, `saturated polychrome`, `surprise interaction`
**Banned:** `restrained palettes`, `minimal motion`, `corporate seriousness`, `predictable interactions`

## Anti-Slop
- [ ] Saturated, vibrant colors
- [ ] Interactive/gamified elements
- [ ] Physics-based or spring motion
- [ ] Surprise moments on interaction
- [ ] Fullscreen immersive sections
- [ ] Playful, energetic aesthetic
- [ ] No restrained or minimal palettes
- [ ] No corporate seriousness
- [ ] No predictable interactions

## When to Use
Campaign microsites, product launches, cultural moments, music/entertainment, Gen-Z brands
