## SPRING & MOTION SYSTEM

```ts
const spring = { type: "spring", stiffness: 300, damping: 15, mass: 0.8 };
const snappy = { type: "spring", stiffness: 500, damping: 22 };
const bouncy = { type: "spring", stiffness: 260, damping: 12 };
```

- Buttons: tilt + scale(1.08) on hover; squash + stretch + confetti on click
- Cards: spring lift + tilt on hover
- Section entry: scale(0.85)→1 with overshoot, scroll into view
- Badges: pop in with overshoot + confetti
- Score counter: scale pulse on gain
- Optional scroll-jacking: scroll scrubs the story sequence (0.8s per section)

`prefers-reduced-motion: reduce` → disable particles, scroll-jacking, idle bobbing; hovers become simple scale; entrance is instant.

## CONTENT GUIDANCE

**Headlines:** 4-7 words, loud, uppercase. "PLAY HARD. CLICK HARDER." not "Explore Our Products."

**Body text:** 1-2 sentences, playful and inviting. Write like a game tutorial, not a marketing pitch.

**Copy tone:** Reward-driven. Frame every action as earning something: "EARN POINTS BY EXPLORING", "COLLECT THE BADGES". Use exclamation energy sparingly — let the motion do the shouting.

**Interactions:** At least one delight moment per section. Confetti on clicks, particle trails on drag, morphs on hover. Never let an element respond the boring way.
