## FLUID SIZE SYSTEM

Use `clamp()` for all sizes — no hard px breakpoints for type/spacing:

```css
:root {
  --pad-x: clamp(1.5rem, 4vw, 3rem);
  --section-gap: clamp(3rem, 8vh, 6rem);
  --logo: clamp(1rem, 1vw, 1.25rem);
  --nav: clamp(0.65rem, 0.3vw + 0.5rem, 0.8rem);
  --headline: clamp(2rem, 4vw, 3.5rem);   /* Confident, not monumental */
  --subhead: clamp(1.25rem, 2.5vw, 2rem);
  --body: 14px;                            /* SMALL — technical document */
  --micro: 10px;                           /* TINY mono labels */
  --border: 1px solid #A8B5A0;
}

## COLOR SYSTEM

```css
:root {
  --ground: [GROUND_COLOR];          /* Pale sage #C8D5C0 or cream #F5F0E8 */
  --ground-elevated: [GROUND_DARKER]; /* Slightly darker for panels */
  --ink: #2A2A2A;                    /* Dark ink — NEVER pure black */
  --ink-secondary: #555555;
  --ink-muted: #888888;
  --border: #A8B5A0;
  --accent: [ACCENT_COLOR];          /* ONE earth-tone accent — see guidance */
}
```

**Ground color guidance:**
- `#C8D5C0` (pale sage) — primary, most versatile
- `#F5F0E8` (cream) — warmer, for heritage brands

**Accent color guidance:** Choose ONE earth tone. Good options:
- `#3D6B4F` (forest green) — safest, most technical
- `#8B6F47` (antique brown) — warmer, heritage feel
- `#A0563A` (survey orange) — for data highlights only

The accent appears ONLY on: primary CTA button, one data point per section, active nav state. Nowhere else.

### Footer
- Ruler tick pattern along top edge
- Footer row: brand name, year, version/status — all in mono

## CONTENT GUIDANCE

**Headlines:** Be specific and technical. NOT "Build the future of analytics." INSTEAD: "Mapping the Unseen" or "Signals, Not Noise."

**Body copy:** Short (max 40 words per block). Specific. Technical register. No filler words ("seamlessly", "leverage", "empower"). Write like a technical document, not a marketing brochure.

**Data callouts:** Use real or plausible numbers with units. `DEPTH: 2.4km`, `PRECISION: 0.1 mGal`, `SENSITIVITY: 0.01 nT`. Monospace font. These are the "technical marginalia" that signal precision.

**Sector codes:** Every section has one. `SECTOR 04-A`, `SECTOR 04-B`, `SECTOR 04-C`. Sequential, referenced, cataloged.
