# Print Tech Paper

**Pale sage ground, topographic contour lines, mono data callouts, transaction-ID chips. A field manual for a future that already happened.**

## Visual DNA
Pale sage (#C8D5C0) or cream (#F5F0E8) ground resembling uncoated stock paper. Topographic contour lines and technical diagrams serve as illustration. Monospace data callouts and transaction-ID chips create a feel of printed technical documentation. Grotesk display type provides authority. Everything feels like a field manual for a future that already happened.

## Design Principles
1. **DATA AS DECORATION** — Coordinates, IDs, ruler ticks aren't metadata — they're design elements
2. **PALE GROUND, DARK INK** — The paper color is the canvas. Dark ink (#2A2A2A, not pure black) is the content
3. **TECHNICAL MARGINALIA** — Every element has a label, a number, a reference

## Typography
- Display: Grotesk (Space Grotesk 600/700), clamp(2rem, 4vw, 3.5rem)
- Body: Clean sans (Inter 400), 14-15px
- Mono labels: JetBrains Mono 400, 10-11px, tracking 0.15em, uppercase

## Color
- Ground: #C8D5C0 (pale sage) or #F5F0E8 (cream)
- Ink: #2A2A2A (dark, not pure black)
- Accent: #3D6B4F (forest green) or #8B6F47 (antique brown)

## Motion
Minimal to none. This is a printed page — static by nature. Subtle fade-ins only (600ms ease-out).

## Layout
- Strict grid, technical margins
- Data callouts positioned at corners/edges
- Topographic illustrations as section backgrounds
- Ruler ticks and coordinate labels throughout

## Texture
- Paper grain (SVG feTurbulence, opacity 0.06)
- Topographic contour line illustrations
- Film-strip ticks along edges
- Halftone dot patterns on data visualizations

## Vocabulary
**Primary:** `topographic contour`, `mono data callouts`, `transaction-ID chips`, `pale sage ground`, `technical marginalia`
**Banned:** `gradient backgrounds`, `bold colorful accents`, `photographic imagery`, `glassmorphism`

## Anti-Slop
- [ ] Pale paper ground (sage or cream, never white)
- [ ] Dark ink not pure black (#2A2A2A)
- [ ] Monospace labels on all data elements
- [ ] Topographic or technical illustration
- [ ] Transaction-ID or coordinate chips
- [ ] Paper grain texture
- [ ] No gradients, no photos, no glass

## When to Use
Technical products, data platforms, scientific tools, documentation sites, architecture firms

## Common Mistakes
1. Using pure white instead of sage/cream → Fix: #C8D5C0 or #F5F0E8
2. Adding photographic imagery → Fix: topographic line illustrations only
3. Using colorful accents → Fix: forest green or antique brown only
4. Making it too clean → Fix: add paper grain and technical marginalia
