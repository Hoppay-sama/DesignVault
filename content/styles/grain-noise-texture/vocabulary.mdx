# Vocabulary Bank

## Primary Terms

| Term | Why It Matters |
|------|---------------|
| `film grain` | The base surface — analog imperfection reintroduced to digital design |
| `noise overlay` | Fixed, full-viewport texture layer — `pointer-events: none`, opacity 0.03-0.08 |
| `paper texture` | The screen reads as a physical surface, not a display |
| `analog` | Human imperfection — misregistration, jitter, tooth |
| `tactile warmth` | The core mood — warmth that digital cleanliness destroys |

---

## Secondary Terms

| Term | Effect |
|------|--------|
| `feTurbulence` | SVG noise filter — procedural grain without image assets |
| `dithering` | Scattered pixel noise that softens banding in muted gradients |
| `chromatic aberration` | Slight RGB channel offset at edges — analog lens imperfection |
| `halftone dots` | Print-process dots as texture — risograph and newsprint feel |
| `risograph misregistration` | Off-register color plates — layered, slightly imperfect ink |
| `paper tooth` | Visible fiber texture of uncoated stock |
| `film jitter` | Subtle 24fps positional shimmer — grain animates like projected film |
| `grain shimmer` | Barely perceptible noise animation — gentle, never distracting |
| `reduced text contrast` | Text isn't pure black on white — softened like printed ink |

---

## Context Terms

| Term | Mood |
|------|------|
| `printed on uncoated stock` | Muted colors that feel absorbed, not glowing |
| `artisan` | Handmade, human, small-batch warmth |
| `editorial` | Serif-led, magazine-like composition |
| `grotesque` | Warm modern sans — pairs with grain without fighting it |
| `warm neutrals` | Stone, sand, clay — grounded, earthy |
| `cool mineral tones` | Slate, graphite, chalk — quiet, grounded alternative |
| `24fps jitter` | The grain moves like film — 24 frames, not 60fps smoothness |

---

## Banned Terms

| Term | Why It Breaks the Style |
|------|------------------------|
| `clinical perfection` | The enemy — this style deliberately reintroduces imperfection |
| `neon colors` | Saturation destroys the printed-on-stock feel |
| `sharp digital edges` | Edges should feel pressed, not cut |
| `glossy surfaces` | Gloss is the opposite of uncoated paper warmth |
| `pure black on white` | Text contrast must be reduced — nothing is fully black or white |
| `smooth gradients` | Banding is fine — dither it, don't hide it |
| `glassmorphism` | Frosted glass is digital — this style is physical |
| `snappy motion` | Motion is gentle, slow, film-like |

## Prompt-Ready Phrases

```
"fixed film grain overlay at 0.03-0.08 opacity (pointer-events: none)"
"SVG feTurbulence noise filter as the primary surface"
"muted desaturated palette — warm neutrals: stone, sand, clay"
"reduced text contrast — no pure black on white"
"grain shimmer — 24fps jitter, barely perceptible, infinite"
"paper fiber and halftone dot textures"
"risograph misregistration — layered, slightly imperfect ink"
"chromatic aberration at edges — subtle analog lens imperfection"
"serif (editorial) or grotesque (modern) type, softened contrast"
"generous whitespace — texture IS the design, layout stays simple"
"slow fades only — 1000ms+, ease-out, no snappy motion"
"no neon, no glossy surfaces, no sharp digital perfection"
```

## Style Axis

```
color: 3   typography: 3   motion: 2   density: 2   texture: 6   layout: 2
```

Texture carries the style (6/6). Color, typography, motion, density, and layout are restrained — the grain IS the design.
