# Editorial Portrait

**Mono with cutout portrait, giant marquee name, editorial serif, cream on dark, single composition, no scroll on hero.**

## Visual DNA
A single composition: brand name, giant scrolling marquee name, one portrait stack (background photo + cutout overlay), minimal chrome (nav/social), footer blurb. The portrait sits on top of the giant name so letters read through the cutout. Cream (#efeee9) on dark/photo. No cards, no pills, no glow. A magazine cover come to life.

## Design Principles
1. **ONE COMPOSITION** — Entire hero is a single layered image. No scrolling. Everything in one viewport
2. **PORTRAIT OVER TYPE** — Cutout portrait overlaps giant marquee, creating depth through layering
3. **MARQUEE AS IDENTITY** — Scrolling name IS the brand presence. Never stops.

## Typography
- Display: Helvetica Neue ME or Ogg Medium, giant marquee scale (16-26vh)
- Body/UI: Same family or clean sans, 14-16px

## Color
- Background: dark photo or near-black
- Text: cream #efeee9
- No purple, no cards, no glow

## Motion
- Infinite horizontal marquee (30s linear infinite)
- Staggered entrance animations (fade-up, cubic-bezier(0.22, 1, 0.36, 1))
- Mobile drawer with staggered reveals

## Layout
- Full viewport hero, overflow-hidden
- Layered: BG photo → marquee → portrait cutout → chrome
- Desktop footer with cream rule line
- Mobile hamburger → drawer

## Texture
- Photographic background
- Clean portrait cutout (transparent PNG)
- Subtle entrance animations only

## Vocabulary
**Primary:** `giant marquee name`, `portrait cutout overlay`, `editorial portrait`, `cream on dark`, `single composition`
**Banned:** `scrolling hero`, `card layouts`, `purple accents`, `multiple sections in hero`

## Anti-Slop
- [ ] Single composition hero (no scroll)
- [ ] Cream (#efeee9) text, not white
- [ ] Portrait cutout layered over marquee
- [ ] Infinite marquee (30s linear)
- [ ] No cards, pills, or glow
- [ ] Editorial serif display font
- [ ] Staggered entrance animations

## When to Use
Personal portfolios, photographer sites, creative directors, editorial features, artist websites
