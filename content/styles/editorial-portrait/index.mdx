# Editorial Portrait

**Mono with cutout portrait, giant marquee name, editorial serif, cream on dark, single composition, no scroll on hero.**

---

## Visual DNA

A single composition: brand name, giant scrolling marquee name, one portrait stack (background photo + cutout overlay), minimal chrome (nav/social), footer blurb. The portrait sits on top of the giant marquee so letters read through the cutout. Cream (#efeee9) on dark/photo. No cards, no pills, no glow. A magazine cover come to life.

The entire hero is one layered image — no scrolling, no sections, no grid. The marquee name scrolls infinitely behind the portrait, creating constant motion within a static composition. The portrait cutout overlaps the marquee, creating depth through layering. This is what a magazine cover would do if it were a website — one image, one name, one composition, infinite presence.
