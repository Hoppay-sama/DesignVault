# Anti-Slop Checklist

Every Editorial Portrait page must pass ALL of these checks before shipping:

- [ ] No pure white (#FFFFFF) text (use cream #efeee9)
- [ ] No accent colors (cream only — no blue, amber, purple)
- [ ] No scrollable hero (single composition, `h-[100dvh]`, `overflow-hidden`)
- [ ] No multiple sections in hero (one composition, one viewport)
- [ ] No card layouts (portrait + marquee only)
- [ ] No pills, badges, or prominent CTA buttons
- [ ] No glow or neon effects
- [ ] No gradient backgrounds (photographic background only)
- [ ] No grid system (absolute positioning, z-index layering)
- [ ] No bounce or spring easing (cubic-bezier(0.22, 1, 0.36, 1) only)
- [ ] No feature grids or multiple content sections in hero
- [ ] No glassmorphic surfaces
- [ ] No grain or noise overlay (the photo IS the texture)
- [ ] No dither or halftone processing (clean photography)
- [ ] Cream text (#efeee9) present
- [ ] Giant marquee name scrolling infinitely (30s linear) present
- [ ] Portrait cutout (transparent PNG) overlapping marquee present
- [ ] Single composition hero (h-[100dvh], overflow-hidden) present
- [ ] Editorial serif or distinctive display font present
- [ ] Minimal chrome (nav and social at edges only) present
- [ ] Staggered entrance animations present
- [ ] Z-index stack correct (photo → marquee → cutout → chrome)
- [ ] Cream rule line (1px hairline) present
- [ ] Mobile drawer with staggered link reveals present
- [ ] `prefers-reduced-motion` is honored (marquee stops, entrances instant)
