# Kinetic Typography

**Type IS the design — monumental display faces that animate, split, morph, and respond to scroll. Letterforms carry all visual weight.**

---

## Visual DNA

Oversized display faces (120px+) that animate, split, morph, and respond to scroll. Words become architectural elements. The page reads like a kinetic poster — letterforms carry all the visual weight, with imagery secondary or absent. Variable fonts with animated axes create living letterforms that breathe and shift.

Every word is choreographed. Scroll-driven type scaling maps variable font weight to scroll progress. Horizontal marquees run continuously. Letters reveal one-by-one with staggered delays. The typography doesn't sit on the page — it IS the page.

## Key Techniques

- **Variable font animation:** Weight axis mapped to scroll (100→900)
- **Split-text reveals:** Letter-by-letter or word-by-word on scroll
- **Horizontal marquee:** Continuous scrolling text strips
- **Scroll-driven scale:** Type grows/shrinks with scroll position
- **Magnetic text:** Letters follow cursor with spring resistance
- **GSAP ScrollTrigger:** Pinned text sequences with scrub
