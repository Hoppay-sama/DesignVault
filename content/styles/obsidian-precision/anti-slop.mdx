# Anti-Slop Checklist

- [ ] No pure #000000 background (use #0A0A0A to #111111)
- [ ] No Inter as display font (use Geist, Satoshi, Inter Tight, or custom)
- [ ] No purple-to-blue gradients
- [ ] No centered hero (left-aligned only)
- [ ] No card shadows (hairline borders only)
- [ ] No glassmorphism or backdrop-blur
- [ ] No more than ONE accent color
- [ ] No bounce or spring overshoot easing
- [ ] No gradient text on headlines
- [ ] No generic 3D illustrations
- [ ] No "Build the future" headlines
- [ ] No equal 3-column feature grids (use asymmetric bento)
- [ ] No rounded corners above 8px
- [ ] No drop shadows on cards
- [ ] Radial glow present behind hero
- [ ] Hairline borders used for structure
- [ ] Monospace font for data/code elements
- [ ] Staggered entrance animations (0.06s delay)
- [ ] Tactile press on buttons (scale 0.98 on :active)
- [ ] `prefers-reduced-motion` honored
- [ ] Hero fits viewport or has generous padding
- [ ] Max 4 text elements in hero stack
