## VISUAL RULES

- Near-black ground (#0A0A0A), off-white text (#E8E8E8), gray accents only
- Accent color (#D4A574) ONLY on CTA button and one data point per section
- No purple, no cream, no glow, no gradients
- All imagery must be dithered (Floyd-Steinberg or halftone) — NEVER raw photography
- Sharp corners only (border-radius: 0-2px max)
- Typography at extremes: monumental display or tiny mono, little middle
- Asymmetric layout — never centered
- Motion: slow orchestrated reveals only, easing `cubic-bezier(0.22, 1, 0.36, 1)`, no bounce
- Honor `prefers-reduced-motion: reduce`
