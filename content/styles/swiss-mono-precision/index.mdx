# Swiss Mono Precision

**Ruthlessly systematic — monochromatic palette, rigid grid, mathematical spacing. Swiss International Style for the digital age.**

## Visual DNA
Strict monochrome (B&W with one muted accent). Neo-grotesque sans (Akkurat, Aeonik, Neue Haas). Mathematical 12-column grid. Hairline rules. Systematic type scale. Generous whitespace as architectural element. Every pixel is justified. The beauty is in the restraint.

## Key Elements
- **12-column grid** with mathematical spacing (8px base unit)
- **Neo-grotesque type** at systematic scale (1.25x or 1.5x ratio)
- **Hairline rules** (1px) as structural elements
- **Asymmetric but derived** — layout looks free but is mathematically locked
- **Micro-typography** — proper dashes, hanging punctuation, tabular figures

## Vocabulary
**Primary:** `Swiss grid`, `systematic spacing`, `neo-grotesque`, `hairline rule`, `mathematical margin`, `modular scale`
**Banned:** `decorative elements`, `gradients`, `rounded corners above 2px`, `asymmetric without system`

## Anti-Slop
- [ ] 12-column grid (or 16-column)
- [ ] Mathematical spacing (8px base unit)
- [ ] Neo-grotesque typeface
- [ ] Systematic type scale (1.25x or 1.5x)
- [ ] Hairline rules for structure
- [ ] Max 2-3 colors (B&W + one accent)
- [ ] Proper micro-typography (dashes, quotes, figures)
- [ ] No decorative elements without function
