# Anti-Slop Checklist

- [ ] Near-monochrome palette (off-white, warm gray, near-black)
- [ ] At most one minimal accent, used sparingly
- [ ] No gradients anywhere
- [ ] Refined serif display for headlines (e.g. Newsreader, Fraunces, Playfair Display)
- [ ] Clean sans-serif for body text (e.g. Inter, Public Sans)
- [ ] Moderate headline sizes (32-48px) — no display extremes
- [ ] `max-w-[65ch]` measure on all body text
- [ ] 1.6+ line height, generous leading
- [ ] Generous whitespace throughout — sections separated by large vertical pauses
- [ ] Clear typographic hierarchy: kicker → headline → deck → body
- [ ] Content-forward, design-invisible interface
- [ ] Minimal navigation — quiet, static, unanimated
- [ ] Single column or simple 2-column layout (no bento, no card grids)
- [ ] Motion limited to a restrained fade-in on scroll
- [ ] Instant or near-instant transitions — nothing bouncy
- [ ] Paper-like, clean surface — no grain, no depth effects
- [ ] No decorative animations
- [ ] No parallax, no floating/sticky trickery
- [ ] No busy layouts or loud colors
- [ ] No spectacle over substance — the words carry the page
- [ ] No template-y minimalism (generic hero + 3 cards + footer)
- [ ] `prefers-reduced-motion` honored (fade-in disabled entirely)
