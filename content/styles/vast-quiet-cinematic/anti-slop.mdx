# Anti-Slop Checklist

- [ ] No pure #FFFFFF background (use fog-white #F5F3F0 or the photograph)
- [ ] No bold or heavy typeface weights (max 400 for display, 500 for body)
- [ ] No centered large headlines (edge-aligned or centered-but-tiny only)
- [ ] No card grids or feature rows
- [ ] No gradients of any kind
- [ ] No raw unprocessed photography (all images must be desaturated + graded)
- [ ] No bright, saturated accent colors
- [ ] No more than ONE accent color
- [ ] No bounce or spring easing (use slow ease-out only)
- [ ] No glassmorphism or backdrop-blur
- [ ] No drop shadows
- [ ] No multiple images per section (one full-bleed image per section)
- [ ] No busy navigation (max 4 links, thin text)
- [ ] Section padding minimum py-48 (don't compress whitespace)
- [ ] Body text max 14px (don't enlarge)
- [ ] Display text max 2rem (don't make it monumental)
- [ ] CTA is quiet (thin border, small text — not a giant button)
- [ ] Hero photograph fills entire viewport
- [ ] Film grain applied (opacity 0.03-0.05)
- [ ] Vignette on all photographs
- [ ] `prefers-reduced-motion` honored
- [ ] No more than 2-3 sentences of body text per section
- [ ] Navigation is transparent over the photograph
