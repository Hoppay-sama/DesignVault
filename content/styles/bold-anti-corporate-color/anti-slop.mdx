# Anti-Slop Checklist

- [ ] Saturated, clashing primary palette (acid yellow #D4FF00, hot pink #FF2D95, electric orange #FF5400, cobalt blue #0049FF, lime green #B6FF00)
- [ ] Full sections on solid saturated fields — no neutral background as the default
- [ ] Collage/overlapping layout with hard edges, never a clean card grid
- [ ] Intentional misalignment — rotated blocks (1–3deg), force-ragged type, clipped by viewport
- [ ] Oversized condensed display type breaking the grid (Anton, Archivo Black, Bebas Neue)
- [ ] Mixed typography styles simultaneously — condensed shout + handwritten scrawl + plain grotesque body
- [ ] Hand-drawn or risograph texture — halftone, grain, ink crush, misregistration
- [ ] Playful, bouncy motion — wobble, overshoot, elastic easing (200–500ms)
- [ ] Ink black (#111111) hard borders, crop marks, stamps on saturated fills
- [ ] Warm cream (#FFF3D6) for "paper" moments — never sterile #FFFFFF
- [ ] Stickers/stamps/handwritten annotations as an overlapping second layer
- [ ] No corporate minimalism, no muted colors, no pastels
- [ ] No safe corporate blue or "trustworthy" navy UI
- [ ] No perfect alignment — nothing optically centered
- [ ] No professional polish — no rounded-glass cards, no subtle shadows, no luxury restraint
- [ ] No gradient-mesh defaults or gradient-to-white softening
- [ ] No timid centered layouts or type with generous letter-spacing
- [ ] No thin or light weights anywhere (restraint reads corporate)
- [ ] No over-saturation chaos — loudness needs fields and hierarchy, not everything at once
- [ ] `prefers-reduced-motion` honored (static, no bounce/wobble/overshoot)
