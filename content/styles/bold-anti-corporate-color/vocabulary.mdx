# Vocabulary Bank

## Primary Terms

| Term | Why It Matters |
|------|---------------|
| `anti-corporate` | The core stance — direct rejection of corporate minimalism |
| `saturated clash` | Clashing saturated primaries used intentionally, not accidentally |
| `risograph texture` | Screen-print grain, off-registration, ink bleed — the zine print look |
| `collage layout` | Overlapping, misaligned, mixed-media composition |
| `punk typography` | Typography that breaks every rule — mixed styles, all at once |

---

## Secondary Terms

| Term | Effect |
|------|--------|
| `acid color` | Electric, eye-searing accents — acid yellow, hot pink, electric orange |
| `risograph misregistration` | Offset color layers that don't perfectly align — visible print error as style |
| `halftone` | Dotted screen-print texture — stippled shadows and gradients |
| `sticker bomb` | Clustered graphic elements layered like stickers on a surface |
| `elastic easing` | Springy, overshooting motion — bounces past the target and settles |
| `wobble` | Slight shaky oscillation — the element never fully sits still |
| `hand-drawn elements` | Rough marker, pen, and scribble marks — imperfect by design |
| `stencil type` | Spray-paint stencil lettering — street/punk voice |
| `intentional misalignment` | Off-grid placement and rotated elements as deliberate composition |
| `grain` | Heavy paper/screen texture over everything — unpolished surface |

---

## Context Terms

| Term | Mood |
|------|------|
| `punk` | Loud, defiant, anti-establishment, unpolished |
| `zine` | DIY print culture — photocopied, stapled, hand-crafted |
| `rebellion` | Color and layout as protest against corporate polish |
| `youth` | Street, skate, music, subculture energy |
| `activism` | Posters, flyers, protest — message over aesthetics |
| `chaotic playfulness` | Bouncy, slightly chaotic motion — playful not broken |
| `imperfection` | Unpolished as the point — personality over polish |

---

## Banned Terms

| Term | Why It Breaks the Style |
|------|------------------------|
| `corporate minimalism` | The exact thing this style rebels against |
| `muted colors` | The palette must be saturated and clashing |
| `perfect alignment` | Misalignment is intentional composition |
| `professional polish` | Imperfection is the point |
| `neutral palette` | Every accent is loud — no quiet neutrals |
| `smooth gradients` | Flat ink blocks and halftones, not digital blends |
| `serious/formal tone` | The voice is irreverent and playful |
| `restrained typography` | Type breaks rules — bold condensed, handwritten, stencil together |

## Prompt-Ready Phrases

```
"flat saturated clashing color blocks — acid yellow, hot pink, electric orange, cobalt blue, lime green"
"risograph texture with visible misregistration on color layers"
"halftone dots for shadows and gradients (screen-print look)"
"sticker-bombed graphic elements — rotated, overlapping, clustered"
"collage composition — overlapping panels, intentional misalignment, off-grid"
"hand-drawn marker/pen elements layered over print blocks"
"oversized condensed display type at 120px+ — loud, unmissable"
"mixed typography — bold condensed + handwritten + stencil used simultaneously"
"elastic easing motion — springy bounce that overshoots and settles (600-900ms)"
"wobble animation — subtle oscillation, element never sits still"
"grain overlay across the whole page (heavy paper/screen texture)"
"sticker/tape visual details — physical DIY materials"
"no corporate minimalism, no muted colors, no perfect alignment, no professional polish"
```
