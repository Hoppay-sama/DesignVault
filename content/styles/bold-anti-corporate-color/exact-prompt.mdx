- **Caveat 700 (handwritten)**: Accent phrases, annotations, scribbles — tilted slightly, inline with display type

- Mixed styles used simultaneously on the same surface — that's the point

## ANIMATIONS

| Element | Animation | Duration | Easing |
|---------|-----------|----------|--------|
| Hero headline | opacity 0→1 + rotate(-2deg)→(-2deg) + translateY(40px)→0 | 500ms | `ease-out` (delay 100ms) |
| Sticker badges | scale(0)→1 with overshoot | 700ms | `backOut` (stagger 120ms) |
| CTA hover | scale(1)→(1.06) | 300ms | `backOut` |
| Panels | translateY(60px)→0 + rotate into place | 600ms | `backOut`, springy |
| Event rows | opacity 0→1 + translateX(-20px)→0 | 400ms | `ease-out` (stagger 80ms) |
| Accent blocks | wobble: rotate ±1.5deg oscillation | 4s | `ease-in-out`, infinite |
| Marquee strip | translateX loop (infinite scroll) | 20s | `linear`, infinite |

`prefers-reduced-motion: reduce` → disable all wobble/marquee/spring, instant entrance.
