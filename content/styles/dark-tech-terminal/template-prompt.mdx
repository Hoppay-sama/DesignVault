### Hero — Terminal Window
- `min-h-[100dvh]`, terminal-window framing: title bar with three traffic dots + path `user@[HOST]:~/[PROJECT]`
- Scan-line overlay across the full hero
- Left-aligned, technical margins (monospace grid, 12-column)

- CTA: "[CTA_LABEL]" — square corners, 1px accent border, phosphor glow on hover

### Metrics / Data Section
- Grid-locked 12-column layout, left-aligned with technical margins
- Metric cards framed as terminal windows (title bar + dots, raised surface, 1px line border, square corners)
- Each: mono uppercase label (10px, 0.15em tracking) + live value (mono 500, accent) + sparkline/ASCII bar

### Features — Code-Editor Aesthetic
- Split: code block (left) + copy (right)
- Code block: gutter line numbers, `>` prompts, accent-colored keywords
- Feature list items prefixed with `[ OK ]` or `>` glyphs
- Headlines: [DISPLAY_FONT] 700, uppercase

### Footer
- ASCII art mark as logo divider (character-based, e.g. `>>-[BRAND]-<<`)
- Copyright line — mono 400, uppercase, 12px, tracking 0.15em, text-muted

## MOTION & TEXTURE

- Typed-text effects: 30-50ms per character
- Blinking caret: 1s `steps(1)` blink
- Terminal-style reveals: staggered 150ms
- Glow pulses on accent elements: 2-3s `ease-in-out` infinite (text-shadow/box-shadow)
- Scan-lines: repeating-linear-gradient, ~3px period, low opacity
- Subtle noise/grain overlay (static)
- Metric count-up: 800ms ease-out

`prefers-reduced-motion: reduce` → instant typing (full text), static caret, no glow pulses.

## VISUAL RULES (DO NOT MODIFY)

- Near-black ground (#0A0F0F) — never white, never light gray
- Single neon accent (cyan / electric green / amber) — one at a time
- Monospace for all data, code, labels, and body copy
- Geometric sans for headlines only
- Scan-line and/or subtle noise texture
- Terminal window framing with title bar + traffic dots
- Typed-text effects with blinking caret
- ASCII art as decoration/dividers
- Grid-locked, dashboard-density layout
- Phosphor glow on accents, not blurry borders
- No warm colors, no serif fonts, no organic shapes, no playful motion

---

## CONTENT GUIDANCE

**Headlines:** 3-6 words, UPPERCASE, imperative or operational. "MISSION CONTROL FOR YOUR INFRASTRUCTURE" not "We Help You Monitor Servers."

**Body text:** 1-2 sentences. Precise, technical, machine-voice. Write like a system readout, not a marketing pitch.

**Typed line:** A command-style phrase, lowercase with `> ` prefix: "> deploying observer agents to 1,284 nodes..."

**Status readouts:** Uptime, latency, node counts, log lines — decorative data that reinforces the terminal frame.
