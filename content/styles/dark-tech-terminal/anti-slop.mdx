# Anti-Slop Checklist

- [ ] Near-black ground (#0A0F0F zinc-950) as the base
- [ ] Monospace for data and technical elements (JetBrains Mono, Fragment Mono, Azeret Mono)
- [ ] Geometric sans reserved for headlines only (Aeonik, Archivo)
- [ ] Single neon accent family — phosphor cyan #00D4FF, electric green, or amber
- [ ] White text for reading; neon only for signals and interactives
- [ ] Grid-locked, data-dashboard layout with strict column alignment
- [ ] Terminal-window framing (title bar, status line, prompt strings)
- [ ] Blinking caret / cursor on typed or interactive text
- [ ] Scan-line, CRT, or code-editor texture (subtle noise, subtle glow)
- [ ] ASCII art where imagery would go
- [ ] Typing animations and terminal-style reveals (~30-50ms per character, no long pauses)
- [ ] Subtle glow pulse on accent elements, not full-screen bloom
- [ ] Monospace readable at small sizes (respect line-height, no ultra-thin weights)
- [ ] `prefers-reduced-motion` honored (static terminal, no typing/caret/glow pulses)
- [ ] No purple-blue gradient "hacker movie" clichés
- [ ] No rainbow/iridescent neon (one accent family maximum)
- [ ] No decorative-only scan-lines — real terminal logic or nothing
- [ ] No serif fonts, warm colors, or organic shapes
- [ ] No playful motion or bouncy easings — mechanical, precise, deterministic
- [ ] No glassmorphism or frosted panels (mission control, not AR overlay)
- [ ] No centered, "marketing hero" layouts — left-aligned with technical margins
