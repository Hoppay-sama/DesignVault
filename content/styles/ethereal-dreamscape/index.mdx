# Ethereal Dreamscape

**Soft pastels, gradient meshes, floating elements, weightless drift, aurora effects. Dream sequence aesthetic.**

## Visual DNA
Soft, floating, otherworldly. Pastel gradients bleed into each other. Elements drift and hover as if weightless. Aurora effects and gradient meshes create surfaces that feel alive but calm.

## Design Principles
1. **WEIGHTLESS COMPOSITION** — Elements float freely, not grid-locked
2. **GRADIENT AS ATMOSPHERE** — Gradient mesh IS the environment
3. **SOFT OVER SHARP** — No hard edges, everything blurs and diffuses

## Typography
- Light-weight sans-serif (Outfit Light, Satoshi Light)
- Generous letter-spacing
- Floating placement

## Color
- Soft pastels (lavender, peach, sky blue, mint)
- Gradient meshes
- Low-saturation aurora effects

## Motion
- Slow drift animations
- Floating elements
- Gentle parallax
- Aurora/mesh gradient animation

## Layout
- Non-grid, elements placed freely in space
- Overlapping translucent layers

## Texture
- Soft blur, gradient mesh
- Cloud-like diffusion
- No hard edges

## Vocabulary
**Primary:** `gradient mesh`, `aurora effect`, `floating element`, `pastel diffusion`, `weightless drift`
**Banned:** `hard edges`, `sharp contrast`, `grid-locked layout`, `bold saturated colors`

## Anti-Slop
- [ ] Soft pastel palette
- [ ] Gradient mesh or aurora effects
- [ ] Floating/drifting elements
- [ ] Gentle, slow motion
- [ ] No hard edges or sharp contrast
- [ ] No grid-locked rigid layout
- [ ] No bold saturated colors

## When to Use
Wellness brands, creative portfolios, experiential campaigns, meditation apps, luxury skincare
