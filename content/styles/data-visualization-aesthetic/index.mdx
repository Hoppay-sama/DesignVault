# Data Visualization as Aesthetic / Living Dashboard

**Charts and metrics as primary visual content. Monospace numbers, precise labels, cockpit density.**

## Visual DNA
Data visualization elevated from utility to design language. Charts, graphs, data points dominate composition. Clean lines, precise labels, elegant scales. Monospace for all numbers with proper decimal alignment.

## Design Principles
1. **DATA AS HERO** — Charts/metrics are primary visual content
2. **PRECISION IS BEAUTY** — Tabular figures, proper decimal alignment, clean gridlines
3. **COCKPIT DENSITY** — Information-rich but organized

## Typography
- Monospace for all numbers (JetBrains Mono, IBM Plex Mono, Geist Mono)
- Clean sans for labels
- Tabular figures
- Micro-labels at 10-11px

## Color
- Dark backgrounds (#0A0A0A to #111827)
- Data in high-contrast colors
- Each series distinct hue
- Gridlines in subtle gray

## Motion
- Real-time data updates with smooth interpolation
- Scroll-triggered chart animations
- Sparkline micro-animations
- Number counting/rolling

## Layout
- Dense but organized
- Grid of metrics, charts, data cards
- Cockpit-like information density

## Texture
- Clean, digital precision
- Subtle glow on active data points
- Grid backgrounds

## Vocabulary
**Primary:** `sparkline`, `tabular figures`, `data-ink ratio`, `cockpit layout`, `live data`
**Banned:** `decorative charts`, `imprecise numbers`, `cluttered layout`, `non-monospace data`

## Anti-Slop
- [ ] Data visualization as primary content
- [ ] Monospace for all numbers
- [ ] Tabular figures, proper decimal alignment
- [ ] Organized density (not cluttered)
- [ ] Real-time or scroll-triggered animations
- [ ] Clean gridlines and labels
- [ ] No decorative or imprecise charts
- [ ] No non-monospace data display

## When to Use
Fintech, analytics products, crypto/blockchain, climate/science communication, sports analytics, annual reports
