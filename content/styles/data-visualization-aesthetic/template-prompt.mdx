## FONTS

Replace [MONO_FONT] with a tabular-friendly monospace and [SANS_FONT] with a clean label sans:

- **IBM Plex Mono (400-600)** — classic dashboard data type
- **JetBrains Mono (400-600)** — modern, developer-grade
- **Geist Mono (400-600)** — geometric, cockpit-appropriate
- Inter / Geist for label text

Load via Google Fonts. Apply `font-variant-numeric: tabular-nums` to all number elements. Use mono for every number (KPIs, chart labels, table cells, tick values); sans for labels and micro-labels (10-11px, uppercase, tracking 0.08-0.1em).

## STRUCTURE

### Top Bar
- Sticky, dark ground, 1px gridline bottom border
- Brand mark (sans, uppercase, tracked) + live ticker line ([METRIC_NAME] updating) + data source stamp — all readouts in mono

### KPI Metric Row (4 cards)
- Grid of metric cards: `bg-panel`, 1px gridline border, rounded
- Each: micro-label + big tabular number + delta chip (green/red) + sparkline
- Numbers count-up on scroll into view

### Main Chart Section
- One hero chart (line/area) on `bg-panel`, subtle gray gridlines, mono tick values, sans axis labels
- Line draws left-to-right on scroll; active point glows subtly; end data label in mono

### Secondary Charts (1-2 panels)
- Bars (allocation/comparison) in categorical hues, scaleY-in with stagger from baseline
- or small multiples strip: repeated mini charts sharing one scale, each with mono value

### Data Table
- Columns: [LABEL / VALUE / DELTA / TREND]. Values and deltas mono tabular-nums, right-aligned, color-coded signs. 16px sparkline per row.
- Hover: faint `bg-white/5` highlight only

### Footer
- Mono, text-faint: brand + update stamp ("DATA UPDATED LIVE · SOURCE: [SOURCE]")

## ANIMATIONS

- KPI count-up 0 → value, 900ms, ease-out (stagger 100ms)
- Line/area draw pathLength 0 → 1, 1200ms, ease-out
- Bar growth scaleY 0 → 1 from baseline, 800ms, ease-out (stagger 100ms)
- Sparkline draws, 600ms, ease-out
- Live ticker number flicker, 400ms, ease-in-out
- Active data point: 4px dot + subtle glow, 2s, infinite

`prefers-reduced-motion: reduce` → skip count-ups/draws/glows, render final state.

## VISUAL RULES (DO NOT EDIT)

- Charts and metrics are the primary visual content, not ornament
- All numbers in tabular monospace with decimal alignment
- Maximize data ink — subtle gridlines, zero chart junk
- Categorical flat palette, one distinct hue per series
- Organized cockpit density — information-rich, never cluttered
- Real-time and scroll-triggered motion: count-up, bar growth, line draw
- Clean sans micro-labels (10-11px), precise axes on every chart
- Dark ground with panels and subtle gridlines

---

## CONTENT GUIDANCE

**Headlines/labels:** 2-5 words, factual, precise. "PORTFOLIO VALUE — 12 MONTHS" not "See How We Grew."

**Numbers:** Real, coherent, consistent series. Same decimal precision across a column, same scale for in-chart comparisons, formatted with thousands separators and fixed decimals where appropriate.

**Writing tone:** Analyst annotation, not a marketing pitch. Short descriptive labels; the data carries the message.

**Data:** Make the series internally coherent (seasonal patterns, monotonic trends, realistic ranges). Label every axis, cite a plausible "source" in the footer so it reads as live.
