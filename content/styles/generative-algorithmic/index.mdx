# Generative Algorithmic

**Procedural visuals, particle systems, noise fields, real-time rendering. Code-as-art. Canvas/WebGL-driven.**

## Visual DNA
Code-as-art. Visuals procedurally generated — particle systems, noise fields, recursive patterns. Page feels alive, different on every visit. Canvas/WebGL-driven, non-traditional DOM.

## Design Principles
1. **CODE IS THE MEDIUM** — Visuals computed, not designed
2. **ALWAYS ALIVE** — Continuous procedural animation
3. **CANVAS OVER DOM** — WebGL/Canvas rendering primary

## Typography
- Monospace or technical sans-serif, secondary to visuals

## Color
- Algorithmically derived palettes
- Gradient-based or noise-field-driven

## Motion
- Continuous procedural animation
- Particle systems
- Noise-driven movement
- Real-time rendering

## Layout
- Canvas/WebGL-driven
- Non-traditional DOM
- Viewport IS the canvas

## Texture
- Digital noise, Perlin noise fields
- Recursive patterns
- Data-driven texture

## Vocabulary
**Primary:** `procedural generation`, `particle system`, `Perlin noise`, `WebGL canvas`, `real-time render`
**Banned:** `static imagery`, `traditional DOM layout`, `CSS-only design`, `stock photography`

## Anti-Slop
- [ ] Procedural/generative visuals
- [ ] Canvas or WebGL rendering
- [ ] Continuous animation
- [ ] Algorithmic color/texture
- [ ] Code as primary medium
- [ ] No static stock imagery
- [ ] No traditional DOM-heavy layout

## When to Use
Creative technologist portfolios, experimental studios, data art installations, music visualizations

## Prompts
**Exact:** Build a generative art page with Canvas/WebGL. Particle system or noise field. Continuous animation. Algorithmic palette. Minimal UI.
