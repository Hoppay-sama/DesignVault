# Data-as-Texture

**Cinematic data clouds — amber binary characters on dark teal sky, data as material, golden accent CTAs, mono labels.**

## Visual DNA
Clouds rendered from amber binary characters against a dark teal (#0D2B3E) sky. Data becomes material — not displayed in charts but woven into the atmosphere itself. Golden accent CTAs glow against the nocturnal palette. Monospace labels anchor the composition in technical precision.

## Design Principles
1. **DATA AS MATERIAL** — Numbers, binary, code aren't content — they're texture forming clouds and atmosphere
2. **NOCTURNAL PALETTE** — Dark teal, deep navy, amber gold. A night-sky aesthetic
3. **MONO ANCHORS** — Small monospace labels provide technical credibility

## Typography
- Display: Clean geometric sans (Space Grotesk 600), clamp(2rem, 5vw, 4rem)
- Body: Inter 400, 14-15px
- Mono labels: JetBrains Mono, 10-11px, tracking 0.15em

## Color
- Sky: #0D2B3E (dark teal)
- Data: #D4A574 (amber binary)
- Ground: #0A1628 (deep navy)
- Accent: #C4956A (golden CTA)

## Motion
Ambient — data clouds drift slowly (CSS animation, 30s linear infinite), binary characters shimmer subtly.

## Layout
- Full-bleed dark sky with binary cloud texture
- Headline left on darkest area
- Data-clouds fill lower right
- Mono data callouts at edges

## Texture
- Binary character clouds (amber text arranged as cloud shapes)
- Data-stream vertical lines (subtle)
- Noise overlay (opacity 0.03)

## Vocabulary
**Primary:** `binary clouds`, `data-as-material`, `amber binary`, `dark teal sky`, `golden accent`
**Banned:** `bright colorful data-viz`, `chart graphs`, `white backgrounds`, `sans-serif data labels`

## Anti-Slop
- [ ] Dark teal/navy ground (not black)
- [ ] Amber/golden data characters
- [ ] Data arranged as atmospheric texture (not charts)
- [ ] Mono labels for all data points
- [ ] Golden CTA accent only
- [ ] No chart/graph visualizations

## When to Use
Data platforms, fintech, analytics, climate tech, AI/ML products, infrastructure
