## HAND-DRAWN UI

```css
.draw-border {
  border: none;
  position: relative;
  filter: url(#wobble); /* SVG turbulence on the stroke */
  stroke: #2B2622;
  stroke-width: 1.5;
  stroke-linecap: round;
  fill: rgba(255, 255, 255, 0);
}

.wobble {
  animation: wobble 3s ease-in-out infinite;
  transform-origin: center;
}

@keyframes wobble {
  0%, 100% { transform: rotate(-0.6deg) translate(0, 0); }
  50% { transform: rotate(0.6deg) translate(1px, -1px); }
}
```

## ANIMATIONS

- Hero illustration: stroke draw-on (stroke-dasharray), 2000ms, ease-out
- Text: opacity 0→1 + translateY, 900-1200ms, ease-out (staggered delays)
- Doodles & accents: subtle wobble, 3s, infinite
- Illustrations: breathing scale(1)→(1.01), 6s, infinite
- CTAs: wobble on hover, hand-drawn underline draws in

`prefers-reduced-motion: reduce` → disable all wobble/breathing/draw-on, instant entrance.
