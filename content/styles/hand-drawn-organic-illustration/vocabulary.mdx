# Vocabulary Bank

## Primary Terms

| Term | Why It Matters |
|------|---------------|
| `hand-drawn` | The core signal — every line, shape, and texture must look made by a human hand |
| `illustration` | Drawn imagery, not photography or render — the page is an artwork |
| `watercolor bleed` | Wet pigment seeping past its stroke — imperfect, alive, human |
| `ink splatter` | Random droplets and drips — happy accidents as design elements |
| `human mark` | Visible imperfection proving human authorship — the anti-AI declaration |
| `bespoke` | Every page element feels custom-drawn for this brand, never templated |

---

## Secondary Terms

| Term | Effect |
|------|--------|
| `line weight` | Thick-to-thin stroke variation — the drawing hand's pressure and confidence |
| `hatching` | Parallel sketch strokes building tone — a pencil, not a fill tool |
| `doodle` | Small loose drawings as decoration — stars, arrows, underlines, faces |
| `marker bleed` | Marker ink soaking into paper, slightly overshooting the stroke |
| `sketch` | Quick, loose, unfinished-looking draft quality — sophistication through restraint |
| `paper texture` | Visible grain underneath everything — the page has a physical surface |
| `eraser marks` | Faint smudges where lines were corrected — the hand made mistakes |
| `wobble` | Lines that drift slightly off-straight — no ruler, no pen tool |
| `outline` | Thick irregular contour around shapes, closing imperfectly |
| `marginalia` | Sketch notes and annotations in the margins as design elements |

---

## Context Terms

| Term | Mood |
|------|------|
| `artisanal` | Made by hand, in small batches, with visible craft |
| `organic` | Shapes follow nature's flow, not geometry |
| `imperfect` | Intentional flaw as the point — charm over polish |
| `warm` | Earthy, welcoming, human temperature |
| `handwritten` | Type that looks penned, with uneven baseline and letterforms |
| `draw-on` | Strokes appearing stroke-by-stroke — the drawing happens in front of you |

---

## Banned Terms

| Term | Why It Breaks the Style |
|------|------------------------|
| `AI-generated imagery` | The style is a declaration of human authorship — no synthetic imagery |
| `perfect geometric shapes` | Circles, squares, and straight lines reveal a machine hand |
| `corporate polish` | Clean, aligned, managed — everything this style rejects |
| `digital precision` | Pixel-perfect edges and exact spacing kill the human mark |
| `smooth gradients` | Transitions must show strokes, bleed, and paper, not blending |
| `perfect symmetry` | A human hand never balances — asymmetry is the rhythm |
| `glossy surfaces` | Physical media (pencil, ink, watercolor) is matte and tactile |
| `sleek motion` | Motion must wobble and breathe — mechanical easing feels fake |

## Prompt-Ready Phrases

```
"hand-drawn line art and doodles as the core imagery"
"visible human mark — wobbly lines, imperfect shapes, varied line weight"
"watercolor bleed and ink splatter as texture"
"marker streaks, pencil grain, eraser marks over paper texture"
"handwritten display type (Caveat, Patrick Hand) with clean sans body"
"warm earthy palette — terracotta, ochre, sage, cream, charcoal"
"bold marker accents — cobalt, vermillion, lemon"
"SVG draw-on animations (stroke-dasharray) — strokes appear stroke by stroke"
"wobble/breathing effects — gentle, organic, nothing mechanical"
"loose asymmetric layout — illustrations break out of containers"
"hand-drawn dividers and marginalia as design elements"
"layout follows the illustration, not the grid"
```
