## STAMPED UI

```css

  display: flex;
  white-space: nowrap;

  clip-path: inset(0 0 100% 0);
  animation: stamp 500ms cubic-bezier(0.16, 1, 0.3, 1) forwards;

  to { clip-path: inset(0 0 0 0); }
}
