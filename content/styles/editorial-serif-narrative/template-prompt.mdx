## STRUCTURE

### Chapter Opener (Hero)
- `min-h-[90vh]`, warm paper background, oversized serif headline
- Headline: [DISPLAY_FONT], `clamp(2.5rem, 6vw, 5rem)`, sentence case
- Standfirst: 1-2 sentences at 1.25x body size
- Folio/issue label: small-caps or italic serif micro-text

### Story Sections (3-4 chapters)
- Each: chapter number (roman numeral), oversized drop cap on first paragraph
- Multi-column body: `columns: 2` (desktop), measure 60-75ch
- Pull quote at 2x body size between sections, centered or offset
- Full-bleed editorial photography between chapters (single image per break)

### About / Colophon
- Single column at 60-75ch, generous line height (1.6-1.7)
- 2-3 paragraphs of narrative voice, not feature list

### Footer
- Paper-toned, hairline top rule, running head + folio styling

## SCROLL-DRIVEN STORYTELLING

```css
.chapter {
  opacity: 0;
  transform: translateY(24px);
  transition: opacity 900ms ease, transform 900ms ease;
}
```

- Chapters fade/rise into view as they enter the viewport (900-1200ms, ease-out)
- Pull quotes: scale 0.96→1 + opacity, 1000ms
- Photography: opacity 0→1 + slight parallax, 1200ms
- Drop caps: static print styling — no entrance animation (they're ink, not UI)

`prefers-reduced-motion: reduce` → disable all reveal motion, instant sections.

## CONTENT GUIDANCE

**Headlines:** 6-12 words. Authoritative, literary. "The Quiet Craft of the Long Read" not "Our Blog Features Essays."

**Standfirsts:** 1-2 sentences. Invites the read — a lede, not a pitch.

**Body:** Write like a magazine feature. Paragraphs 2-4 sentences. Let whitespace breathe — never wall-to-wall text.

**Imagery:** Editorial photography (not stock): portraits, environments, still life — full-bleed, art-directed, one mood per image.
