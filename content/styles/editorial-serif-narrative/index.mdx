# Editorial Serif Narrative

**Magazine-quality layout with serif headlines, drop caps, pull quotes, and long-form storytelling rhythm.**

## Visual DNA
Serif display headlines (PP Editorial New, Canela, Domaine) paired with clean sans body. Multi-column text at 60-75ch. Pull quotes breaking the grid. Drop caps on opening paragraphs. Full-bleed editorial photography interrupting text flow. Feels like reading a New Yorker feature, but interactive.

## Key Elements
- **Drop caps** on first paragraph of each section
- **Pull quotes** at 2x body size, centered or offset
- **Multi-column** CSS columns or grid (2-3 columns on desktop)
- **Editorial photography** full-bleed between text sections
- **Folio/running heads** like a magazine

## Vocabulary
**Primary:** `editorial serif`, `drop cap`, `pull quote`, `column width`, `measure`, `ink-on-paper`
**Banned:** `sans-serif headlines`, `single column only`, `no whitespace between paragraphs`

## Anti-Slop
- [ ] Serif display font (not sans)
- [ ] Drop cap on opening paragraphs
- [ ] Pull quote at least once per long section
- [ ] Body text 60-75ch max width
- [ ] Line height 1.6-1.7 for body
- [ ] Editorial photography (not stock)
- [ ] No sans-serif headlines
