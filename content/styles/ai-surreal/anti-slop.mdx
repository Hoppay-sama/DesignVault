# Anti-Slop Checklist

- [ ] AI/synthetic imagery as hero (not realistic photography)
- [ ] Full-bleed surreal compositions (image-dominant)
- [ ] Desaturated pastel base palette (dusty, faded, memory-like)
- [ ] Rare saturated accents within desaturated fields
- [ ] Morphing transitions between states (latent space interpolation)
- [ ] Drift motion — slow, continuous, barely perceptible (8-12s)
- [ ] Breathing/pulsing animation on imagery and UI
- [ ] Translucent text (85% opacity) floating over imagery
- [ ] Minimal text — imagery carries 90% of visual weight
- [ ] Intentional AI artifacts featured (not hidden)
- [ ] Impossible materials and hybrid surfaces in imagery
- [ ] Iridescent, morphing UI surfaces (not flat or geometric)
- [ ] Neutral sans-serif at light weight (Geist, Inter)
- [ ] No realistic stock photography
- [ ] No corporate or geometric precision
- [ ] No sharp edges — everything morphs and drifts
- [ ] No snappy or fast motion (1000ms+ minimum)
- [ ] No card-based layouts
- [ ] No solid color backgrounds (imagery is the background)
- [ ] No text-heavy sections
- [ ] No saturated palette (saturation is the rare accent)
- [ ] `prefers-reduced-motion` honored (static, no drift/morph/breathing)
