# When to Use

## Perfect For

| Context | Why This Style Works |
|---------|---------------------|
| **AI/ML companies** | The aesthetic literally embodies the product — synthetic, machine-imagined |
| **Creative tech** | The dreamlike, experimental aesthetic signals creative capability |
| **Experimental portfolios** | Artists and designers exploring AI as a medium |
| **Art direction for tech brands** | The surreal aesthetic differentiates from corporate tech design |
| **Music visuals** | The dreamlike, morphing quality matches ambient and experimental music |
| **Generative art platforms** | The style showcases what generative tools can create |
| **Fashion (avant-garde)** | The impossible materials and surreal compositions push fashion forward |

## Brand Personality Match

This style reinforces brands that are:
- **Synthetic** — embracing AI and machine generation as aesthetic
- **Dreamlike** — ethereal, morphing, not grounded in reality
- **Experimental** — pushing boundaries, not following conventions
- **Visual-first** — imagery carries the message, text is secondary
- **Uncanny** — comfortable with the uncanny valley

## Avoid When

| Context | Why It Fails |
|---------|-------------|
| **Corporate/B2B** | Too surreal, too experimental for professional services |
| **E-commerce** | The image-dominant layout can't support product grids |
| **News/journalism** | The dreamlike aesthetic undermines credibility |
| **Healthcare** | The uncanny, synthetic quality is the opposite of reassuring |
| **Government/legal** | Too experimental, too "internet" |
| **Content-heavy sites** | The minimal text and image-dominant layout can't support long-form content |
| **Brands needing trust** | The surreal, morphing aesthetic feels unstable and dreamlike |

## How to Decide

Ask: **"Does my brand want to feel like a machine's dream — synthetic, surreal, and unapologetically AI-generated?"**

If yes → AI-Surreal / Latent Space.
If no → Consider Ethereal Dreamscape (if you want dreamy without AI), Dark Cinematic Studio (if you want dark and atmospheric), or Generative Algorithmic (if you want computational but precise).
