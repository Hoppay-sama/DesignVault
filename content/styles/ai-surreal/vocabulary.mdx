# Vocabulary Bank

## Primary Terms

| Term | Why It Matters |
|------|---------------|
| `latent space` | The space of possible images — the source of all AI imagery |
| `synthetic media` | AI-generated imagery embraced as aesthetic, not hidden |
| `dreamlike` | Slow, morphing, impossible — the core mood |
| `morphing transitions` | One state slowly becoming another — latent space interpolation |
| `desaturated pastels` | The base palette — faded, memory-like, dusty |

---

## Secondary Terms

| Term | Effect |
|------|--------|
| `impossible materials` | Surfaces that don't exist in reality — liquid metal flowers, glass clouds |
| `hybrid surfaces` | Materials blending — flesh becoming stone, water becoming light |
| `scale ambiguity` | Objects at impossible scales — tiny galaxy, massive cell |
| `intentional artifacts` | AI glitches featured as design elements |
| `saturated accents` | Vivid colors within desaturated fields — vivid memory in faded dream |
| `drift motion` | Slow, continuous, barely perceptible movement |
| `breathing` | Subtle scale/opacity pulsing — the page is alive |
| `iridescent surface` | Oil-on-water shimmer — desaturated rainbow |
| `morphing border` | Border-radius that slowly shifts — organic, living shape |
| `translucent text` | 85% opacity text floating over imagery |

## Context Terms

| Term | Mood |
|------|------|
| `dream` | Slow, morphing, impossible, vivid accents |
| `memory` | Faded, desaturated, with vivid remembered details |
| `latent space interpolation` | One image slowly becoming another |
| `uncanny valley` | Almost real but not quite — the AI aesthetic |
| `machine imagination` | Images that could only come from a machine |
| `surreal` | Impossible, dreamlike, beyond reality |
| `ethereal` | Light, floating, insubstantial |

---

## Banned Terms

| Term | Why It Breaks the Style |
|------|------------------------|
| `realistic photography` | The imagery must be synthetic, not real |
| `geometric precision` | Everything should be organic, morphing, imprecise |
| `corporate minimalism` | Too clean, too professional — this is dreamlike, not corporate |
| `sharp edges` | Everything morphs, drifts, blends |
| `snappy motion` | Motion is slow, dreamlike, morphing |
| `saturated palette` | Base is desaturated — saturation is the rare accent |
| `card-based layout` | Full-bleed imagery with floating text, not cards |
| `text-heavy` | Imagery carries 90% of the weight — text is minimal |
| `solid backgrounds` | The imagery IS the background |
| `digital gradients` | Iridescent, morphing, oily surfaces — not smooth gradients |
