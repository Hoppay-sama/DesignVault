## SCROLL CHOREOGRAPHY

### Lerp Smoothing
```javascript
let current = 0, target = 0;
const lerpFactor = 0.14; // 0.10-0.15 range
current += (target - current) * lerpFactor;
```

### Segment-Based Scenes (define 4-5 scenes)
| Scene | Scroll Range | Enter | Hold | Exit |
|-------|------------|-------|------|------|
| Title | 0-[S1]px | Rise | Hold | Fade out |
| [SCENE_2] | [S2_START]-[S2_END]px | [ENTER_EFFECT] | Hold | [EXIT_EFFECT] |
| [SCENE_3] | [S3_START]-[S3_END]px | [ENTER_EFFECT] | Hold | [EXIT_EFFECT] |
| Sights slider | [S4_START]-[S4_END]px | Fly-in from 420vw | Hold | — |
| Nav | [S5_START]-[S5_END]px | Fade in | — | — |

### segmentInOut Helper
```javascript
function segmentInOut(scroll, start, end) {
  const t = (scroll - start) / (end - start);
  if (t < 0 || t > 1) return 0;
  if (t < 0.3) return t / 0.3;
  if (t > 0.7) return (1 - t) / 0.3;
  return 1;
}
```

## TECHNIQUES

- **Blur ramp:** 0px → 14px on exiting layers (depth-of-field transition)
- **Brightness shift:** 1.0 → 0.85 on exiting layers
- **Saturation ramp:** 60% → 100% on entering layers
- **Shade gradient:** opacity 0 → 0.25 → 0 at scene boundaries
- **Mouse parallax:** (optional) 0.12 factor, depth-weighted per layer
- **Infinite slider:** 3-set clone with instant-jump normalize
- **Sight card fly-in:** from 420vw with power(1.55) easing
