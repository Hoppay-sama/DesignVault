# Monochrome + Single Accent / Signal Line

**Full grayscale spectrum with one surgical accent color. Restraint as design statement. Beacon through neutrality.**

## Visual DNA
Radical restraint. Full grayscale with exactly one saturated color used surgically for CTAs, active states, and key data points. The accent becomes a beacon — everything else recedes into sophisticated neutrality.

## Design Principles
1. **ONE ACCENT, TOTAL RESTRAINT** — Accent on ≤15% of surface area
2. **VALUE DOES THE WORK** — Hierarchy from light/dark contrast, not color
3. **ACCENT AS PATH** — Color creates visual pathways through composition

## Typography
- Clean sans-serif (Geist, Outfit, Cabinet Grotesk)
- Weight and size do hierarchy, not color
- Mono for technical details

## Color
- Full grayscale (zinc-950 through zinc-50)
- ONE accent: electric blue, emerald, signal orange, or hot pink
- Accent on ≤15% of surface area

## Motion
- Precise, minimal
- Accent color draws attention to state changes
- Hover reveals accent on grayscale elements

## Layout
- Structured, grid-based
- Accent creates visual pathways

## Texture
- Clean to subtle grain
- No competing textures

## Vocabulary
**Primary:** `accent color`, `color restraint`, `grayscale`, `chromatic pop`, `surgical accent`
**Banned:** `multiple accents`, `colorful palette`, `gradient backgrounds`, `rainbow effects`

## Anti-Slop
- [ ] Full grayscale base
- [ ] ONE accent color only
- [ ] Accent on ≤15% of surface
- [ ] Value-based hierarchy (not color)
- [ ] Clean, no competing textures
- [ ] No multiple accent colors
- [ ] No gradient or rainbow effects

## When to Use
Developer tools, data products, premium SaaS, fintech, technical documentation

## Prompts
**Exact:** Build a monochrome page with full grayscale palette and ONE surgical accent (blue/emerald/orange). Restraint as design. Accent on CTA and key data only.

**Template:** Build a [BRAND] page with grayscale palette and one accent color. Restraint and precision. Accent used surgically.
