## ANIMATIONS

- Entrances: opacity 0→1 + translateY(8-12px), 400-500ms, ease-out, staggered
- Accent beacon: subtle pulse (2000ms, infinite) — accent draws attention to state changes
- Hover: border-color + scale(1.01), 150ms — hover reveals accent on grayscale elements
- Motion is precise and minimal — no drift, no morphing, no breathing backgrounds

`prefers-reduced-motion: reduce` → instant entrances, remove pulse.
