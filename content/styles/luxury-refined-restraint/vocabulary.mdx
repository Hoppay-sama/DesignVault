# Vocabulary Bank

## Primary Terms (must appear in prompt to unlock the style)

| Term | Why It Matters |
|------|---------------|
| `museum whitespace` | The defining signal — vast, curated emptiness |
| `gallery spacing` | Section gaps of 6rem+ — space as the luxury material |
| `refined restraint` | The governing philosophy — nothing excessive |
| `luxury serif` | Editorial serif display (Canela, Domaine, Cormorant) |
| `whispered confidence` | The emotional register — quiet authority |
| `considered placement` | Every element deliberately positioned |
| `desaturated palette` | Ivory/stone/charcoal neutrals, one accent max |
| `extreme leading` | Body line-height 1.7-1.9 — the typographic signature |

---

## Secondary Terms (refine and tune the output)

| Term | Effect |
|------|--------|
| `ivory ground` | Warm off-white #FAF7F2 background |
| `champagne accent` | Flat gold #B9975B used once per page |
| `hairline rule` | 1px warm-neutral divider lines |
| `wide-tracked labels` | 10px uppercase, tracking 0.25em+ |
| `sentence case serif` | Headlines in sentence case, never all-caps |
| `small body text` | 14-16px body with 1.8 line-height |
| `single focal point` | One primary element per viewport |
| `natural light photography` | Soft window light, consistent direction |
| `material surfaces` | Stone, linen, paper — never glass |
| `noir mode` | Espresso-black variant #141210 |
| `oxblood accent` | Deep red #6B2323 editorial option |
| `emerald accent` | Deep green #23402F heritage option |
| `micro label` | 10px uppercase metadata ("EST. 1987") |
| `quiet asymmetry` | Calm 55/45 splits, never dramatic imbalance |
| `artisanal photography` | Real materials, real craft, no stock energy |

---

## Context Terms (set the mood and emotional register)

| Term | Mood |
|------|------|
| `quiet luxury` | The 2020s term for understated wealth |
| `museum-quality` | Curated, lit, preserved |
| `timeless` | Outside any design trend cycle |
| `expensive darkness` | The noir variant's intimate register |
| `heritage` | History, craft, permanence |
| `atelier` | The workshop where craft happens |

---

## Banned Terms (if these appear, the style has broken)

| Term | Why It Breaks the Style |
|------|------------------------|
| `gradient` | Color transitions are retail energy |
| `glassmorphism` | Digital glass vs. physical material |
| `neon` / `glow` | Nightclub, not atelier |
| `playful` / `fun` | Luxury is serious |
| `bold` / `black` (weights) | The style whispers |
| `Inter` / `Roboto` / `Arial` | Default fonts = default taste |
| `card` / `dashboard` | Cards are SaaS furniture |
| `bounce` / `spring` | Motion is a slow crossfade |
| `marquee` | Scrolling text is retail |
| `3D` / `render` | Real materials only |
| `vibrant` / `colorful` | One accent maximum |
| `modern` (as a style word) | Dated the moment it's said |

## Prompt-Ready Phrases

Copy-paste these directly into prompts:

```
"museum whitespace with gallery spacing between sections"
"refined editorial serif display in sentence case"
"ivory ground (#FAF7F2), soft black text (#262220)"
"one champagne accent (#B9975B) used once per page"
"body text at 15px with 1.8 line-height, 62ch measure"
"wide-tracked uppercase micro labels at 10px, tracking 0.3em"
"natural light photography, consistent soft window light"
"hairline dividers instead of cards or borders"
"slow crossfade entrances, 1200ms+, no bounce"
"no gradients, no glassmorphism, no neon, no cards"
```
