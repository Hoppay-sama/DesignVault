# Anti-Slop Checklist

- [ ] Vast whitespace as the dominant design element (py-48+ sections)
- [ ] Refined serif display type (Cormorant Garamond, Canela, Domaine) with a clean sans for body
- [ ] Museum-quality photography — art-directed, soft-lit, single subject
- [ ] Gallery spacing — elements separated like artworks in a gallery
- [ ] Muted, desaturated warm palette (ivory, champagne, stone, espresso)
- [ ] At most one rich accent used sparingly (oxblood, emerald, deep gold)
- [ ] Small, refined body text with generous leading
- [ ] Slow, elegant motion — crossfades and gentle image reveals (600ms+)
- [ ] Considered, deliberate placement — every element earns its position
- [ ] Subtle paper or stone texture, imperceptible at a glance
- [ ] Design disappears — the subject, not the decoration, carries the message
- [ ] No loud gradients or color transitions
- [ ] No neon, saturated, or high-contrast color
- [ ] No clutter, busy layouts, or dense information
- [ ] No decorative or playful motion — nothing bounces, slides, or spins
- [ ] No cheap stock photography or glossy, synthetic-looking imagery
- [ ] No card-based grid saturation — single-column focus, gallery rhythm
- [ ] No more than two typefaces, no display-font novelty
- [ ] No emoji, stickers, or playful UI chrome
- [ ] No centered marketing clichés — no confetti, no fireworks, no parallax spectacle
- [ ] `prefers-reduced-motion` honored (static, no fades or reveals)
