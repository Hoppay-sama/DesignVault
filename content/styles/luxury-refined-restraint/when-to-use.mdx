# When to Use

## Perfect For

| Context | Why This Style Works |
|---------|---------------------|
| **Luxury fashion houses** | The restraint signals price before the price is seen — whispered confidence |
| **High-end real estate** | Vast whitespace and gallery spacing make properties feel museum-worthy |
| **Fine jewelry & watches** | Single-subject photography and slow reveals frame precious objects |
| **Premium artisan brands** | Considered placement echoes craft and hand-made care |
| **Haute couture & ateliers** | The refined serif and muted palette match tailoring and heritage |
| **Luxury hotels & hospitality** | The calm, spacious feel translates directly to the guest experience |
| **Private banking / wealth advisory** | Quiet, timeless confidence beats any claim of sophistication |

## Brand Personality Match

This style reinforces brands that are:
- **Restrained** — confident enough not to shout
- **Timeless** — durable, not trend-chasing
- **Considered** — every detail deliberate, nothing accidental
- **Exclusive** — scarcity and space signal rarity
- **Whispered** — understatement as a luxury signal

## Avoid When

| Context | Why It Fails |
|---------|-------------|
| **Startups needing fast comprehension** | Restraint reads as empty when there is no brand gravity behind it |
| **SaaS / developer tools** | Dense functionality fights the whitespace; users lose affordances |
| **E-commerce (high-volume)** | Gallery spacing cannot support dense product grids |
| **News / daily content** | Slow reveals and vast whitespace frustrate high-frequency readers |
| **Playful or youth brands** | The formality feels cold, distant, and unapproachable |
| **Performance marketing pages** | The calm aesthetic lacks the urgency conversion requires |
| **Content-heavy documentation** | Single-column gallery pacing cannot house long-form information |

## How to Decide

Ask: **"Does my brand need to feel expensive — calm, considered, and confident enough to whisper?"**

If yes → Luxury Refined Restraint.
If no → Consider Quiet Editorial (if you want the calm without the price-signal formality), Editorial Serif Narrative (if you want refined type with more text and story), or Monochrome Single Accent (if you want minimal but with stronger graphic presence).
