# Retro-Futuristic / Chrome Millennium

**Iridescent chrome, holographic gradients, Y2K optimism, inflatable 3D type, black backgrounds making chrome pop.**

## Visual DNA
The optimistic futurism of 1998-2004 reimagined with modern rendering. Chrome text effects, holographic gradients, inflatable 3D type. Black backgrounds make chrome pop. Not ironic pastiche — genuine reclamation of millennium visual language.

## Design Principles
1. **CHROME IS THE MATERIAL** — Metallic gradients with high specular highlights. Chrome extruded lettering.
2. **NOSTALGIA WITH CRAFT** — References Y2K but renders with modern shaders. Not a Windows 98 screenshot.
3. **IRIDESCENCE AS ACCENT** — Holographic rainbow reflections on hover.

## Typography
- Display: Inflated/bubble 3D type, Orbitron, Eurostile Extended
- Body: Clean sans or pixel fonts for contrast
- Size: Monumental (8vw+)

## Color
- Ground: #000000 (pure black — makes chrome pop)
- Chrome: linear-gradient with silver/white/blue shifts
- Accents: electric blue #0066FF, hot magenta, acid green
- Holographic: rainbow gradient shifts

## Motion
- Bouncy spring physics
- Floating/rotating 3D objects
- Liquid metal morphing
- Scanline effects, CRT flicker on hover

## Layout
- Centered, poster-like compositions
- Large hero type with orbiting 3D elements
- Spatial/scene-based, not grid-based

## Texture
- Chrome/metallic shaders
- Holographic rainbow reflections
- Scanlines, pixel dithering, lens flare

## Vocabulary
**Primary:** `chrome type`, `holographic`, `iridescent`, `Y2K aesthetic`, `inflatable type`, `metallic shader`
**Banned:** `flat design`, `minimalist`, `muted colors`, `subtle animations`

## Anti-Slop
- [ ] Chrome/metallic text effects
- [ ] Holographic or iridescent accents
- [ ] Black ground (makes chrome pop)
- [ ] 3D or inflated type elements
- [ ] Y2K-inspired decorative elements
- [ ] Bouncy/energetic motion
- [ ] No flat or muted design

## When to Use
Music/entertainment, Gen-Z brands, streetwear, gaming, crypto/web3, creative agencies, event sites
